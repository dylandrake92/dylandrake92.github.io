# Enhancement Two: Algorithms and Data Structures

## Artifact Description
The artifact used for Enhancement Two is a Node.js and Express REST API backed by MongoDB using Mongoose. This application was previously enhanced during Enhancement One to improve software design, structure, and maintainability. For Enhancement Two, the same approved artifact was extended to demonstrate algorithmic reasoning and data structure usage by improving how collections of data are processed, validated, and returned through the API. This enhancement was completed as part of the CS 499 capstone to demonstrate growth in applying algorithmic principles within an existing, non-trivial system.

## Justification for Inclusion and Skills Demonstrated
I selected this artifact for the algorithms and data structures category because it provides a realistic context for demonstrating algorithmic problem-solving beyond basic CRUD operations. Rather than creating a new or isolated example, this enhancement builds directly on an existing codebase and improves how data is retrieved and managed at scale. Enhancement Two focuses on implementing pagination, sorting, and filtering algorithms for the tutorial listing endpoints. User-provided query parameters are validated and transformed into structured data objects that control execution flow. Pagination is implemented by converting page and pageSize values into calculated offsets using skip and limit logic, ensuring that only the necessary records are retrieved. Sorting is handled through allow-listed fields and controlled direction values to maintain predictable behavior and prevent invalid execution paths.

## Reflection on the Enhancement Process
Working on Enhancement Two reinforced the importance of intentional algorithm design in systems that must handle variable input and evolving data sets. A key lesson was that even common features such as pagination and sorting require careful validation and structure to avoid inefficiencies and errors. The primary challenge was balancing flexibility for users with safety and maintainability within the API. This was addressed by validating inputs, restricting allowable values, and returning consistent metadata that client applications can rely on. I verified the enhancement by running automated tests using Jest and Supertest (npm test) and by manually validating endpoint behavior while the server was running (npm start). This process strengthened my understanding of how algorithmic logic, data structures, and testing work together to produce reliable, professional-quality software. Enhancement Two represents a clear progression from improving structure in Enhancement One to applying algorithmic reasoning to improve system behavior and performance.

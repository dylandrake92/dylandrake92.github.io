Enhancement One: Software Design and Engineering

Artifact Description

The artifact selected for this enhancement is a Node.js and Express REST API backed by MongoDB using Mongoose. The application provides CRUD functionality for a Tutorial resource, including endpoints to create, retrieve, update, and delete records. The original version of this artifact was created prior to CS 499 as a starter REST API project and was selected early in this course as the foundation for my ePortfolio. I used the original implementation as a baseline for conducting a formal code review and identifying software design and engineering improvements.

Justification for Inclusion and Improvements

I selected this artifact for my ePortfolio because it demonstrates practical backend software engineering skills that align with industry expectations. The project showcases my ability to evaluate an existing codebase and apply targeted design improvements rather than developing a solution from scratch. For this enhancement, I improved the overall structure and maintainability of the application by separating application configuration from server startup logic, which simplifies testing and improves clarity. I implemented centralized error handling to standardize API responses and prevent sensitive internal details from being exposed. I also added input validation and field whitelisting for create and update operations to reduce the risk of invalid or unexpected data being persisted. Finally, I added automated tests using Jest and Supertest to verify key API behaviors and protect against regressions. These changes demonstrate my ability to apply professional software design practices that improve reliability, security, and maintainability.

Course Outcomes and Outcome Coverage

This enhancement met the course outcomes I planned to address in Module One. Specifically, it demonstrates my ability to use well-founded tools and techniques to implement computing solutions that deliver value through improved design and structure. The addition of centralized error handling and validation reflects a security mindset by anticipating common failure cases and mitigating potential design flaws. This enhancement also supports clear technical communication through consistent response patterns and testable behavior. My outcome coverage plan remains unchanged, with future enhancements focused on algorithmic improvements such as filtering, sorting, and pagination, as well as database-level improvements including schema constraints and indexing.

Enhancement Two: Algorithms and Data Structures

Artifact Description

The artifact used for Enhancement Two is a Node.js and Express REST API backed by MongoDB using Mongoose. This application was previously enhanced during Enhancement One to improve software design, structure, and maintainability. For Enhancement Two, the same approved artifact was extended to demonstrate algorithmic reasoning and data structure usage by improving how collections of data are processed, validated, and returned through the API. This enhancement was completed as part of the CS 499 capstone to demonstrate growth in applying algorithmic principles within an existing, non-trivial system.

Justification for Inclusion and Skills Demonstrated

I selected this artifact for the algorithms and data structures category because it provides a realistic context for demonstrating algorithmic problem-solving beyond basic CRUD operations. Rather than creating a new or isolated example, this enhancement builds directly on an existing codebase and improves how data is retrieved and managed at scale.

Enhancement Two focuses on implementing pagination, sorting, and filtering algorithms for the tutorial listing endpoints. User-provided query parameters are validated and transformed into structured data objects that control execution flow. Pagination is implemented by converting page and pageSize values into calculated offsets using skip and limit logic, ensuring that only the necessary records are retrieved. Sorting is handled through allow-listed fields and controlled direction values to maintain predictable behavior and prevent invalid execution paths.

Course Outcomes and Planned Coverage

In Module One, I planned to use this enhancement to demonstrate competency in applying algorithmic principles to improve an existing system rather than developing a standalone solution. This milestone satisfies that plan by showing measurable improvements to data handling logic, execution efficiency, and correctness. The enhancement demonstrates progress toward program outcomes related to designing and evaluating computing solutions using appropriate algorithms and practices. No updates to my planned outcome coverage are required, as the work completed aligns directly with the original enhancement plan.

Reflection on the Enhancement Process

Working on Enhancement Two reinforced the importance of intentional algorithm design in systems that must handle variable input and evolving data sets. A key lesson was that even common features such as pagination and sorting require careful validation and structure to avoid inefficiencies and errors. The primary challenge was balancing flexibility for users with safety and maintainability within the API. This was addressed by validating inputs, restricting allowable values, and returning consistent metadata that client applications can rely on.

I verified the enhancement by running automated tests using Jest and Supertest (npm test) and by manually validating endpoint behavior while the server was running (npm start). This process strengthened my understanding of how algorithmic logic, data structures, and testing work together to produce reliable, professional-quality software. Enhancement Two represents a clear progression from improving structure in Enhancement One to applying algorithmic reasoning to improve system behavior and performance.

Enhancement Three: Databases

Artifact Description

The artifact selected for this enhancement is a RESTful API developed using Node.js, Express, MongoDB, and Mongoose. The application manages tutorial records and supports full CRUD functionality along with filtering, sorting, and pagination. The original version of this artifact was created in earlier coursework and has been progressively enhanced throughout CS 499. This enhancement focuses specifically on improving the database layer by strengthening data integrity, validation, and query performance.

Justification for Inclusion in ePortfolio

This artifact was selected for inclusion in my ePortfolio because it demonstrates practical database skills that are commonly required in professional software development environments. The enhancement reflects an understanding of how backend systems manage and protect data while supporting efficient access patterns.

Skills and Abilities Demonstrated

Schema-level constraints were added to enforce required fields, limit string lengths, and apply default values, ensuring that data stored in the database remains consistent and valid. Update operations were configured to enforce validation rules, preventing invalid data from being introduced during modifications. Indexes were designed and applied to support common filtering and sorting operations, improving query efficiency.

Reflection on the Enhancement Process

This enhancement improved my understanding of how application-level database validation operates in a NoSQL environment and how update operations require explicit configuration to maintain data integrity. I also gained experience designing indexes based on real query usage. Overall, this work strengthened my ability to design reliable and efficient database-backed applications aligned with professional software development practices.

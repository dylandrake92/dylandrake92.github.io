Enhancement Three: Databases

Artifact Description

The artifact selected for this enhancement is a RESTful API developed using Node.js, Express, MongoDB, and Mongoose. The application manages tutorial records and supports full CRUD functionality along with filtering, sorting, and pagination. The original version of this artifact was created in earlier coursework and has been progressively enhanced throughout CS 499. This enhancement focuses specifically on improving the database layer by strengthening data integrity, validation, and query performance.

Justification for Inclusion

This artifact was selected for inclusion because it demonstrates practical database skills commonly required in professional software development environments. The enhancement highlights the ability to enforce data integrity, design efficient query patterns, and integrate database solutions into a backend application architecture.

Enhancement Summary

The database layer was enhanced by adding schema-level constraints to enforce required fields, length limits, and default values. Update operations were configured to enforce validation rules, ensuring data integrity during modifications. Indexes were designed and applied to support filtering and sorting operations, improving query performance. Automated tests were used to verify correct behavior and confirm the existence of indexes.

Reflection

This enhancement improved my understanding of how application-level schema validation operates in a NoSQL environment and how update operations require explicit configuration to maintain data integrity. I also gained experience designing indexes based on actual query usage. Overall, this work strengthened my ability to design reliable and efficient database-backed applications.

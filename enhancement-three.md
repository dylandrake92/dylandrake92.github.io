# Enhancement Three: Databases

## Enhancement: https://github.com/dylandrake92/node-express-mongodb/tree/enhancement-3

## Artifact Description
The artifact selected for this enhancement is a RESTful API developed using Node.js, Express, MongoDB, and Mongoose. The application manages tutorial records and supports full CRUD functionality along with filtering, sorting, and pagination. The original version of this artifact was created in earlier coursework and has been progressively enhanced throughout CS 499. This enhancement focuses specifically on improving the database layer by strengthening data integrity, validation, and query performance.

## Justification for Inclusion in ePortfolio
This artifact was selected for inclusion in my ePortfolio because it demonstrates practical database skills that are commonly required in professional software development environments. The enhancement reflects an understanding of how backend systems manage and protect data while supporting efficient access patterns.

## Skills and Abilities Demonstrated
Schema-level constraints were added to enforce required fields, limit string lengths, and apply default values, ensuring that data stored in the database remains consistent and valid. Update operations were configured to enforce validation rules, preventing invalid data from being introduced during modifications. Indexes were designed and applied to support common filtering and sorting operations, improving query efficiency.

## Reflection on the Enhancement Process
This enhancement improved my understanding of how application-level database validation operates in a NoSQL environment and how update operations require explicit configuration to maintain data integrity. I also gained experience designing indexes based on real query usage. Overall, this work strengthened my ability to design reliable and efficient database-backed applications aligned with professional software development practices.
